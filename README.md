--NUVORA

Es una aplicación web de gestión integral orientada a 
organizaciones sociales, fundaciones y centros de atención, 
diseñada para centralizar en una sola plataforma la gestión 
de pacientes o beneficiarios, profesionales, apoderados, fichas,
sesiones, pagos y seguimiento de atenciones. Además, incorpora módulos
para la administración de benefactores, donaciones y procesos asociados
a cooperativas, integrando así la operación asistencial, administrativa, 
financiera y de sostenibilidad económica de la organización.
